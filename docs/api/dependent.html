create

POST /dependents_management_intents/{dependents_management_intent_id}/dependents

Operation ID: AddDependentsToDependentsManagementIntent.

Authentication: bearer token (bearerAuth).

Parameters

| Parameter | In | Type | Required | Description | | --- | --- | --- | --- | | dependents_management_intent_id | path | string | Yes | | | Idempotency-Key | header | string | No | Unique key to ensure idempotent requests. If the same key is used for multiple identical & successful requests, the same response will be returned. Read more here | | X-Platform-Id | header | string | No | The target platform id. Required only when calling with a dashboard (WorkOS AuthKit) access token instead of a platform API key, the token carries no platform claim, so the caller must say which platform it means. Ignored for platform API key / embed session token callers. |

Request body

application/json

The request body is object.

Responses

200: OK

application/json

Property Type Required Description
action_required object No Details of the action required from the caller. Populated only when status is action_required and a required action has been recorded on the intent (for example restricted dependents detected by compliance screening).
coverage_options null,array No Available member-scoped coverage options for the plan. Present when the plan has member-scoped coverage configurations.
dependents array of object Yes List of dependents being managed.
dependents[].associated_person_id string Yes The associated person ID. Prefixed with ap_.
dependents[].coverage_selections null,array No Coverage option selections for this dependent. Populated when member-scoped selections have been provided.
dependents[].requirement_id null,string No The adaptive requirement ID for this dependent. Populated when the dependent has an open adaptive requirement (status is action_required). Prefixed with ar_.
dependents[].status enum: pending_confirmation, action_required, ineligible, processing, restricted, ready Yes The status of this dependent in the dependents management intent.
disclosures array of object Yes Disclosures associated with this intent.
disclosures[].category enum: regulatory, provider, intermediary Yes The category of the disclosure.
disclosures[].text string Yes The disclosure statement text.
disclosures[].type enum: intermediary_role, intermediary_commission, underwriter_disclaimer, anti_selection_notice, statement_of_needs, product_information, ... Yes The specific type of disclosure within its category.
id string Yes Unique identifier for the dependents management intent. Prefixed with dmi_.
object string No Object type identifier.
parent_intent_id string Yes The parent intent ID (for example Policy Amendment Intent ID). Prefixed based on type.
parent_intent_type enum: policy_amendment_intent, enrolment_intent Yes The type of parent intent.
plan object Yes Plan information including pricing details.
status enum: action_required, processing, completed, not_undertaken Yes Current status of the dependents management intent.
